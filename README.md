## ✨ Highlights

- Hero with an **animated card + live-transaction mockup**
- **Working waitlist form** that returns a queue position
- Feature grid, animated stats band, ambient glow effects
- Smooth motion throughout, mobile-first responsive

## 🧱 Tech stack

| Layer | Tech |
|-------|------|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Motion | Framer Motion + GSAP |
| 3D | Three.js / React Three Fiber |
| Icons | Lucide |

## 🚀 Run locally

```bash
npm install
npm run dev
npm run build
```
