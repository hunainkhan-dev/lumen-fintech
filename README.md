# Lumen — Neobank Launch Site

Fintech waitlist landing concept. React + Vite + Tailwind + Framer Motion.

**Highlights:** hero with an animated card + live-transaction mockup, working waitlist form that returns a queue position, feature grid, stats band, ambient glow.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Portfolio case study for **Hunain**. Lumen is a fictional product; no real financial data.
